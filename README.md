# MateAventuras 🚀🔢
¡Juega, descubre y conquista retos matemáticos!

MateAventuras es una aplicación web gamificada para estudiantes de primer grado de primaria. Permite a los niños aprender matemáticas mediante misiones en distintos mundos, y ofrece a los docentes un panel de control avanzado con generación de contenido mediante Inteligencia Artificial.

## 🛠️ Requisitos e Instalación
1. Clonar o descomprimir el repositorio.
2. Crear un entorno virtual e instalar dependencias:
   `pip install -r requirements.txt`
3. Renombrar `.env.example` a `.env` y colocar tu clave de OpenAI (opcional para IA).
4. Inicializar la base de datos y ejecutar la aplicación:
   `streamlit run app.py`

## 🧪 Pruebas
Ejecuta las pruebas automatizadas con: `pytest tests/`
